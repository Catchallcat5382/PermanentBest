BEST BAR v1.5.5

1. Extract this folder over your current Best Bar source folder.
2. Run BUILD.bat to configure, build, package, and install the mod.
3. Completed levels now show a full-width shiny gold bar immediately from saved 100% data.
4. Active best-chase attempts fill gold from the left edge to the current percentage.
5. The LET'S GO freeze feature and its asset were removed completely.
6. The leaderboard now shows player, time, level, difficulty, rewards, level ID, and validity in a green/cyan Geometry Dash-style panel.
7. Existing local leaderboard saves remain readable; new entries store the added level metadata.

Target: Geode 5.8.2 / Geometry Dash 2.2081 / Windows x64
Mod ID: catchallcat5382.best-bar
