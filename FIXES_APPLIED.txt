PERMANENT BEST v1.1.2 - GITHUB JSON/BOM FIX

- Fixed mod.json cloud parse error: expected value at line 1 column 1.
- Root cause: Windows PowerShell 5.1 `Set-Content -Encoding UTF8` writes a UTF-8 BOM.
- All metadata writes now use System.Text.UTF8Encoding(false).
- PUSH.bat validates JSON and verifies the first bytes are not EF BB BF before staging.
- BUILD.bat runs the same metadata normalizer before CMake.
- Geode SDK value remains exactly `5.8.2` without a leading `v`.
- GitHub repository creator files were removed because the repository is already created.
