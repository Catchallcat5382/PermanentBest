PERMANENT BEST v1.1.1

1. Close Geometry Dash.
2. Run BUILD.bat to compile and install locally.
3. Run CREATE_GITHUB_AND_RELEASE_ONCE.bat once to create the GitHub repository, push the source, build it with GitHub Actions, and publish v1.1.1.
4. Open Geometry Dash and check Permanent Best in the Geode mod list.
5. Normal levels show the saved best directly on the progress bar.
6. Platformer levels have a Gold Speedrun button in the lower-right of the pause menu.

Gold Speedrun records are separate from normal platformer times. Failed Gold Runs are also saved.
