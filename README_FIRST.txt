PERMANENT BEST v1.1.2

THE GITHUB REPOSITORY ALREADY EXISTS.

1. Extract this ZIP over your existing PermanentBest / PermaBest project folder.
2. Run PUSH.bat. It validates mod.json, removes any UTF-8 BOM, increments the patch version, pushes main, waits for GitHub Actions, downloads the .geode, and installs it.
3. Run RELEASE.bat after the build succeeds to publish the downloaded .geode as a GitHub release.

Do not rerun the deleted GitHub-creator script.
