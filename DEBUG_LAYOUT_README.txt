BEST BAR LIVE LAYOUT DEBUG

1. Build/install this version normally.
2. Run DEBUG_LAYOUT.bat.
3. Enter any normal level so the progress bar is visible.
4. Click and drag the gold bar. The gold bar and diamond move as one group.
5. Release the mouse to save. Close Geometry Dash when finished.

Debug mode only remains active while DEBUG_LAYOUT.bat is waiting for Geometry Dash.
The chosen X/Y offsets are saved in Best Bar's Geode saved data and are applied normally afterward.
This updates the mod's saved layout values rather than rewriting src/main.cpp while the game is running.
